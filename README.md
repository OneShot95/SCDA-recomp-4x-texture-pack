# SCDA recomp 4x texture pack

[Download the texture pack from Releases](../../releases) — download the base ZIP and all five numbered texture ZIPs.

I created this for my own private use. The texture pack is fully AI upscaled, and I have no coding experience.

4x AI texture upscale preview for Splinter Cell Double Agent v2 recomp.

## Installation
1. Download SCDA-4x-HD-base.zip and ALL FIVE numbered texture ZIPs from this release.
2. Extract all six ZIPs into the SAME folder, merging the textures folder. These are separate ZIPs; extract each one.
3. Put your original Xbox Double Agent .iso in assets, then run SCDA.exe.
4. Keep both executable filenames unchanged for mission loading.

F10 opens settings. Choose 3840x2160 for a 4K display if desired. No Python, AI model or texture processing is needed to play.

## Contents and preview status
4x environment replacements, higher-resolution HUD/icons and original font outlines. Presentation art is 3840x2880, preserving the original 4:3 aspect ratio; its extra size above the AI 4x output is a conventional resize. UI layout and font glyph positions remain original. Normal maps and masks use separate processing; numeric lookup textures stay original.

Iceland was visually tested and prison activation was confirmed in logs. Whole-game coverage is incomplete. Unsupported or ambiguous textures use originals. Some loading screens are modified by the game and may retain original resolution. Versus coverage is partial and has not been visually verified.

No ROM, saves or personal settings are included. README.txt contains the installation notes; SHA256SUMS.txt contains checksums for all six ZIPs.
